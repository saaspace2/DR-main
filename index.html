    About APTOS Dataset & Integration

    The APTOS 2019 Blindness Detection dataset from Kaggle contains thousands of retinal fundus photographs collected from rural India by Aravind Eye Hospital. Images were graded 0–4 for DR severity. To connect your trained ONNX model, place your model.onnx file in the same directory as this HTML file and call loadONNXModel('./model.onnx') in the init section. The preprocessing pipeline handles 224×224 resizing and ImageNet normalization automatically.


    ⚠ This system is intended for clinical decision support only. All diagnoses must be confirmed by a qualified ophthalmologist. Not a standalone clinical diagnostic tool.

    How to Use
